# Amazon Clone

A frontend Amazon clone built using HTML, CSS, and JavaScript.

## Features

- Product listings
- Add to cart functionality
- Quantity updates
- Responsive cart page
- Modular JavaScript structure

## Technologies Used

- HTML
- CSS
- JavaScript
- Git & GitHub

## Project Setup

1. Clone the repository

```bash
git clone https://github.com/atharv894/Amazon-Clone.git
```

2. Open the project folder

3. Run the project using Live Server or open `amazon.html`

## Learning Goals

This project was built while learning:
- DOM manipulation
- JavaScript modules
- Objects and arrays
- Git and GitHub workflow
